# Tugas Python: datetime dan time

Delapan praktikum mandiri berdasarkan materi Programiz yang diberikan.

## Menjalankan

Gunakan Python 3.8 atau lebih baru. Tidak perlu memasang paket tambahan.

```bash
python run_all.py
```

Di Linux/macOS perintahnya dapat berupa `python3 run_all.py`.
Menjalankan satu materi:

```bash
python praktikum/03_strptime.py
```

## Isi proyek

- `praktikum/`: delapan file Python sesuai urutan topik.
- `run_all.py`: menjalankan semua program dan merekam hasilnya.
- `hasil/hasil_run.txt`: output asli, metadata lingkungan, dan exit code.
- `hasil/hasil_run.json`: output yang sama dalam struktur JSON.
- `LAPORAN.md`: laporan dengan output dan pembahasan setiap praktikum.

Hasil pengujian yang disertakan: **8/8 program berhasil**, Python 3.12.14.
Lihat laporan untuk referensi delapan tautan Programiz.

## Catatan

Contoh disusun ulang untuk melatih konsep utama tiap tautan, bukan menyalin semua contoh.
Jam sekarang dan durasi sleep berubah ketika dijalankan ulang.
WIB memakai offset tetap UTC+07:00; zona lokal mengikuti pengaturan komputer.
Format nama hari/bulan mengikuti locale. Runner memperbarui file dalam `hasil/`,
sedangkan `LAPORAN.md` tetap merupakan catatan run yang disertakan.

## Upload ke GitHub

1. Ekstrak ZIP ini.
2. Buat repository baru di akun GitHub.
3. Pilih **Add file > Upload files**.
4. Unggah isi folder proyek: folder `praktikum`, folder `hasil`, dan file lainnya.
5. Simpan dengan **Commit changes**.
6. Salin URL repository yang benar-benar dibuat untuk pengumpulan tugas.

Upload isi hasil ekstraksi agar kode dan laporan dapat dibaca langsung di GitHub.
